# Música ambiental

Coloca tu archivo autorizado de “Spring (It’s a Big World Outside)” — ConcernedApe / Stardew Valley en:

`public/assets/audio/granja-theme.mp3`

No se incluye, descarga ni redistribuye la canción. Asegúrate de que tu autorización permite servirla en este sitio web público.
Después de colocar el archivo, vuelve a desplegar el proyecto. El botón de música de la barra superior
inicia la reproducción con una interacción del usuario: loop y volumen 22 %. Desactivarlo pausa;
reactivarlo continúa desde la misma posición. El reproductor permanece montado al cambiar de edificio.
No se descarga audio al abrir la página. Mientras no exista el archivo, el juego sigue funcionando
sin música y el botón indica que aún no está disponible.
